# Nutrir desde la Raiz

Sitio del programa Nutrir desde la Raiz - Lic. Jorgelina Mainero, M.N. 1868.
Villa Maria, Cordoba, Argentina.

Sitio en vivo: https://jsmainero-stack.github.io/nutrir-desde-la-raiz/

## Archivos

- `index.html` - landing principal
- `el-programa.html` - como es el programa por dentro
- `metodologia.html` - la mirada integral y sistemica
- `herramientas.html` - las cinco herramientas
- `estilos.css` - sistema visual completo
- `comun.js` - barra de progreso, reproductor de audio del hero
- `img/` - imagenes del sitio
